# INNOVARE
📸 ABDesign Fotos — Análise e Melhoria de Processos
📌 Sobre o projeto

Este projeto acadêmico tem como objetivo analisar os processos da empresa ABDesign Fotos, buscando identificar etapas que possam ser melhoradas, automatizadas ou reorganizadas.

A proposta é estudar o funcionamento atual da empresa e desenvolver sugestões que possam contribuir para o aumento da eficiência operacional, melhoria da experiência do cliente, aumento das vendas e, consequentemente, da lucratividade.

A ABDesign Fotos trabalha com produtos como:

Momentos Preciosos, Foto Lembranças, Formatura

Neste projeto, o processo escolhido para primeira análise foi o Foto Lembranças.

🎯 Objetivo

O principal objetivo é mapear o processo atual de Foto Lembranças e identificar possíveis oportunidades de melhoria.

A partir dessa análise, pretende-se propor soluções que possam:

reduzir etapas manuais;
diminuir possíveis erros;
melhorar a organização das informações;
agilizar o atendimento e o processo de vendas;
facilitar a comunicação entre empresa, escola e responsáveis;
melhorar a experiência de compra;
contribuir para o aumento das vendas e dos resultados da empresa.
